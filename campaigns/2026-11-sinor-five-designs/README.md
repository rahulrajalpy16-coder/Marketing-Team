# Sinor five design test pages (2026-11-08)

Rahul asked for five very different design directions for the Sinor Marine Technologies website, one test home page each, using all available photos. Built by five frontend-developer subagents (one per design), photos collected by a separate agent from the partner sites and brochures. Director checked every page at 390 and 1440 wide (screenshots, console errors, external requests, overflow, scroll reaches the end).

Designs: 1 Bridge Instrument (dark HUD), 2 Chart Room (light cartographic), 3 Blueprint Atlas (engineering drawing), 4 Editorial Industrial (bold print style), 5 Deck to Keel (sky to seabed story).
Review status: self-reviewed by the builders and the Director, no independent web-qa-reviewer run.
Files (HTML with embedded photos, about 3 to 8 MB each) are not in this repo by rule. They were sent to Rahul in chat.
