# Sources for the DP system pages (text on pages DP-01 and DP-02)

## Marine Technologies, Bridge Mate brochure MT-SAL-0002 v1.0 (held in Rahul's Drive, read this session)
- Bridge Mate DP 1: "a single control computer, one operator station, and separate I/O units interfacing the sensors, positioning reference system, power source, and thrusters." An independent joystick system can be interfaced to comply with class rules.
- Bridge Mate DP 2: "composed of the same modules as the DP 1 system, but the number of modules has been increased for redundancy ... uses three control computers and minimum two operator stations. Using three control computers makes it possible to perform majority voting ... dedicated I/O unit for each set of sensors, each position reference system, each power source, and each thruster." "Upgrading from a DP 1 to a DP 2 system is an easy process since the same hardware modules are used."
- Bridge Mate DP 3: "triple-redundant DP controller ... minimum of three operator stations ... three I/O units ... physically separate, fire-safe compartment where one control computer, one operator station, and one sensor I/O unit have to be located."
- Joystick: "can be delivered as a stand-alone, independent system or as an integrated unit that is part of a DP configuration."

## NAVIS NavDP 4000 (Sinor's own proposals, recorded in repo Claude-Agent-Team-SMS knowledge/technical/EQUIPMENT_SCOPE_CATALOGUE.md section 4, USER-SUPPLIED, not checked against OEM)
- DP1: NavDP 4011 + NavDP 4001 IJ; one DP station, one IJ station, mode selector, printer, VRS.
- DP2: NavDP 4022 (DP A and DP B stations) + NavDP 4002 IJ; printers, VRS.
- Interface capacity: thruster interfaces by dry contact, 4-20 mA, 0-10 VDC; serial sensor list includes gyro, DGPS, wind, laser, radar, HPR, taut wire.
- Register items for NAVIS: control computers, DP display, DP printer, DP UPS, hardware/software interface, third gyro interface, DP upgrade, critical spares.
