- Non-hero contrast beyond the script's DOM-based check (it skips background images and semi-transparent fills).

## Candidate lessons for the Director

1. Prove a hand test can fail: run the same test with the fix disabled in the browser (route interception) and record the old numbers next to the new ones. Done here for W1.
2. A draft marker is not a fix for an unconfirmed claim. Slots S32 and S33 flag W3 and W4 but the claims still render; keep W3 and W4 on the launch checklist until Rahul answers fact_check Q1 and Q4.
3. When a fix pass adds a new slot type or label, update the launch grep so it counts `[data-slot]` as well as the text "NEEDED FROM RAHUL"; add S32 and S33 to the slot register.
4. Builder phrases such as "wraps cleanly" should name the widths tested; one heading wrapped well at 1024 and left an orphan word at 1440.
5. Compare `getAttribute` not `.href` when checking URLs that contain upper-case placeholders; the browser lowercases hosts and makes a false mismatch.
