## Candidate lessons for the Director
- When a dictated partner name is ambiguous, check the user's own project files before the web; the README resolved Fugro and SMT context quickly.
- Do not expand acronyms (ADIPEC, SMT, MT, EEI) in public copy unless an official source or Rahul states the expansion.
- Prefer the exact text printed on the equipment (for example "Sonardyne SPRINT-Nav") over model variants found in layout documents.
- Third-party event listings disagreed on dates; always anchor dates on the venue or organiser page.
