# QA Checklist: Technical Marine Content

- T1 Every specification, compatibility statement, interface, protocol and certification claim is tagged VERIFIED (with source), USER-SUPPLIED, or UNVERIFIED.
- T2 No UNVERIFIED claim is phrased as a fact to the client.
- T3 Units, ranges and numeric values match the cited sources exactly.
- T4 System names and model names are exactly as the user or OEM writes them (for example Ranger 2, SPRINT-Nav).
- T5 Integration responsibilities are stated correctly (for example, DP integration by the DP manufacturer unless told otherwise).
- T6 Safety-relevant statements (DP class, redundancy, trials) are conservative and sourced.
- T7 Assumptions and data still needed from the client are listed.
