# QA Checklist: Design and Visualization

- D1 When a reference was supplied, compare the output to it visually (render both to PNG) and list differences. Do not claim fidelity without that comparison.
- D2 Minimal-change requests: unrelated areas are identical to the original (pixel or code diff).
- D3 Proportions, colours and branding match approved values (navy about #0D4A85 for Sinor).
- D4 Responsive at phone width (390 px) with no horizontal scroll.
- D5 Interactive elements work (load headlessly and exercise them).
